# 森林資源量メッシュ（20m）生成プラグイン（forest_mesh20m）

森林資源量集計メッシュ（20m・国土基本図図郭ベース）の**格子だけを作成する** QGIS プラグイン。
準拠仕様: 森林情報に関するオープンデータ標準仕様書 Ver.2.1【航空レーザ森林資源解析データ編】（令和8年8月版）

## 機能

Processing ツールボックス → 「森林資源量メッシュ（20m）」

### ① 20m メッシュを作成（国土基本図図郭ベース）

| パラメータ | 内容 |
|---|---|
| 系番号 | 平面直角座標系 I〜XIX（初期値 IX） |
| 測地系 | JGD2011（初期値）/ JGD2000 |
| 出力する形状 | ポリゴン / ポイント（中心点）/ ライン（格子線） |
| 作成範囲 **または** ファイル単位図郭名 | どちらか一方。図郭名は `04HE2, 04HE3` のように複数可 |
| 作成するメッシュ数の上限 | ポリゴン/ポイントのみ。既定 100 万件（超えると中止） |

### ② 20m メッシュを図郭ごとに出力（GeoPackage）

範囲と交差するファイル単位図郭を自動で列挙し、`fr_mesh20m_{図郭}_{整備年}.gpkg`（仕様書 表2.1）を
1 図郭ずつ順次書き出す。GeoPackage 内のレイヤ名はファイル名から拡張子を除いたもの。

| パラメータ | 内容 |
|---|---|
| 系番号 / 測地系 / 出力する形状 | ①と同じ（ラインは選べない） |
| 作成範囲 **または** ファイル単位図郭名 | どちらか一方 |
| 図郭全体を出力する | オフ（既定）: 「作成範囲」で端の図郭を切り取る。オン: 交差する図郭を丸ごと出力 |
| 整備年 | 西暦 4 桁。**必須**（ファイル名に使用） |
| 出力後にレイヤを読み込む | オフ（既定）。オンで完了後に QGIS へ読み込む（**10 ファイルまで**。超えると警告して読み込まない。1 ファイル 75 万フィーチャで描画が重い）。**実機未確認** |
| 作成するファイル数の上限 | 既定 100 |
| 出力フォルダ | なければ作成。**同名ファイルが 1 つでもあれば、何も書かずに中止**（上書きしない） |

出力属性（暫定名）: ポリゴン/ポイントは `JF20mID`（12桁）と `file_zukaku`。ラインは `kind` と `boundary_no`。
属性名は `algorithms/common.py` の定数 4 つで変更できる。

**負荷の目安**（推定）: 38,514 件を約 0.55 秒で書けた実測から、1 図郭（75 万件）は約 11 秒。

### ③ 20m メッシュを領域ポリゴンに合わせて作成（領域ごとに別レイヤ）

流域・県・解析範囲などのポリゴン 1 件につき 1 レイヤを、1 つの GeoPackage（または一時レイヤ）に作る。

- 入力: 領域レイヤ（選択地物のみも可）、マスクレイヤ（任意。地域森林計画対象林など。「領域 ∩ マスク」を対象にする）、系、測地系。
- 採用（既定）: 領域（マスクがあれば領域∩マスク）と正の面積で交差する 20m 正方形を、厳密な交差面積で判定し、被覆率（400㎡ に対する割合）がしきい値以上のセルを採用する。しきい値 0 は、正の面積で重なれば採用（線や点で接するだけのセルは除く）。
- 複数の領域にまたがるメッシュ: 既定は交差する領域すべてに、正方形の全体を重複して入れる（境界のセルは両方のレイヤに入る）。「1 領域にだけ割り当てる（旧方式・近似）」も選べる。
- 出力: GeoPackage（推奨。同名ファイルがあれば中止）／一時レイヤ（メッシュ数の合計に上限。超えたら中止）。
- 属性（暫定名）: `JF20mID`, `file_zukaku`, `cover_pct`（被覆率 [%]、整数）。
- ログ: 領域ごとの被覆率の分布、しきい値で落とした面積、他領域へ割り当てた面積。マスクなしのときは領域面積との差が 1% 超で警告。
- 旧方式（排他割当）は近似（細分数 n で分解能 1/(n x n)）。既定の重複出力は厳密な交差面積。マスクの空間索引はメモリ上で自動作成する（事前作業不要）。
- 領域は 1 つの系の中に収まる必要がある（収まらない領域はエラー）。複数の系にまたがる地域の自動切り分けは v0.5 予定。

## インストール（QGIS）

`forest_mesh20m-plugin-v0.4.2.zip` を、QGIS のメニュー「プラグイン」→「プラグインの管理とインストール」→
「ZIP からインストール」で指定する。旧版が入っている場合は先にアンインストールする。

## 動作確認（②を最初に使うとき）

1. 系 VIII・図郭名 `08LE1`・整備年 `2026`・ポリゴン・出力フォルダを指定して実行する。
2. `fr_mesh20m_08LE1_2026.gpkg` ができ、75 万件が入っていること。先頭の `JF20mID` が `08LE00000000`（末尾は `08LE44149199`） であること。
3. ログに出力先が表示されること。実行後にファイルが開けること（書き込みが確定しているか）。
4. もう一度同じ設定で実行して、「同名のファイルが既にある」ため中止されること。

## 動作確認（③を最初に使うとき）

1. 小さな領域（流域 1〜2 件、マスクなし）・細分数 5・しきい値 0・GeoPackage 出力で実行する。
2. ログに領域ごとの採用数・被覆率の分布が出ること、GeoPackage に領域ごとのレイヤができること（QGIS に読み込んで領域の形に沿うこと）。
3. 隣り合う領域の境界で、同じ `JF20mID` が両方のレイヤに入っていないこと。
4. マスクを指定して、マスクの外にメッシュが出ないこと。
5. 同じ設定でもう一度実行すると、同名ファイルがあるため中止されること。

## 仕様書に記載がなく、本実装で仮定している点

1. 【本プラグインの仕様】メッシュ境界線上の点は、南側・東側のメッシュに入れる（floor 方式。東西は [西辺, 東辺)、南北は (南辺, 北辺]）。標準仕様書には記載がない。
2. ファイル単位図郭の枝番は 1=北西, 2=北東, 3=南西, 4=南東（図2.3、兵庫・鳥取の図郭割図、兵庫 2025 の公開データで確認済み）。
3. 属性名は暫定（本文の表は `JF20mID`、参考3 の図5 は `JP20mID`。正式名は今後決定）。
4. EPSG コードは規則（JGD2011=6668+系, JGD2000=2442+系）による。系VIII・JGD2011（6676）のみ実機で確認。JGD2024 は未対応。
5. GeoPackage 内のレイヤ名はファイル名から拡張子を除いたもの。

- ③の被覆率しきい値の既定値（現在 0。実測した分布から決める）と、一時レイヤの上限の既定値（300,000。目安）。
- アルゴリズム②の「出力後にレイヤを読み込む」の実機動作（②の出力自体は QGIS 3.44.11 で確認済み）、系VIII 以外と JGD2000 の EPSG、QGIS 3.34 / 3.40、Python 3.9、Qt6 版 QGIS。
- ファイル単位図郭の枝番の公式との照合。
