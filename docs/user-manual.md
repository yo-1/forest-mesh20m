# 操作マニュアル：森林資源量メッシュ（20m）生成プラグイン

バージョン 0.4.0（実験版）／QGIS 3.34 以降（動作確認は 3.44.11・Windows）

このマニュアルは、インストールから、結果の確認、うまくいかないときの対処までを、手順で説明します。アルゴリズム③は実機でまだ実行されていません。最初は小さなデータで試してください。

## 1. どのアルゴリズムを使うか

| やりたいこと                                                       | 使うもの                                     |
|--------------------------------------------------------------------|----------------------------------------------|
| 小さな範囲のメッシュ・格子線を 1 つのレイヤに作りたい              | ① 20m メッシュを作成（国土基本図図郭ベース） |
| 広い範囲を、ファイル単位図郭ごとの GeoPackage に分けたい           | ② 20m メッシュを図郭ごとに出力（GeoPackage） |
| 流域・県・森林などのポリゴンに合わせて、領域ごとのレイヤを作りたい | ③ 20m メッシュを領域ポリゴンに合わせて作成   |

## 2. インストールと削除

### 2.1 インストール

1. 旧版が入っている場合は、先にアンインストールする（下の 2.2）。

2. QGIS のメニュー「プラグイン」→「プラグインの管理とインストール」を開く。

3. 左の「ZIP からインストール」を選び、forest_mesh20m-plugin-v0.4.0.zip を指定して「プラグインをインストール」を押す。

4. 「インストール済み」タブで「森林資源量メッシュ（20m）生成プラグイン」にチェックが入っていることを確認する。

5. 「Processing ツールボックス」を開き（メニュー「プロセッシング」→「ツールボックス」）、「森林資源量メッシュ（20m）」グループにアルゴリズムが 3 つあることを確認する。

ツールボックスにグループが出ない場合は、QGIS を再起動してください。これでも出ない場合は「7. うまくいかないとき」を見てください。

### 2.2 削除（元に戻す方法）

「プラグインの管理とインストール」→「インストール済み」→ このプラグインを選んで「プラグインをアンインストール」。作成済みの GeoPackage は削除されません。

## 3. ① 20m メッシュを作成

1. ツールボックスで「20m メッシュを作成（国土基本図図郭ベース）」をダブルクリックする。

2. **平面直角座標系の系番号**を選ぶ（例：山梨・長野・新潟・静岡は VIII）。既定値は IX なので注意。

3. **測地系**を選ぶ（通常は JGD2011）。

4. **出力する形状**を選ぶ（ポリゴン／ポイント／ライン）。

5. 範囲を指定する（どちらか一方）。

    - 「作成範囲」：右端のボタンから「キャンバス上をクリック」「レイヤから計算」などを選ぶ。

    - 「ファイル単位図郭名」：08LE1 のように入力。複数はカンマ・空白区切り。小文字・全角でも可。

6. 「メッシュ数の上限」は既定の 100 万のままでよい（1 図郭は 75 万件）。

7. 出力先（一時レイヤ、ファイルへ保存など）を選び、「実行」を押す。

**確認**：ログに「対象メッシュ数」と座標系（例 EPSG:6676）が出る。属性テーブルに JF20mID と file_zukaku がある。

## 4. ② 20m メッシュを図郭ごとに出力

1. 「20m メッシュを図郭ごとに出力（GeoPackage）」を開く。

2. 系番号・測地系・形状を選ぶ。

3. 範囲を「作成範囲」か「ファイル単位図郭名」のどちらか一方で指定する。「作成範囲」で端の図郭を全体出力したいときは「図郭全体を出力する」をオンにする。

4. **整備年**を西暦 4 桁で入力する（必須）。

5. 「出力後にレイヤを読み込む」は、必要なときだけオンにする（10 ファイルまで、1 ファイル 75 万件で描画が重くなる）。このオプションは実機で未確認です。

6. 出力フォルダを指定して「実行」。

**確認（例：系VIII・図郭 08LE1・整備年 2026）**

- fr_mesh20m_08LE1_2026.gpkg ができている。

- 75 万件が入っている。先頭の JF20mID は 08LE00000000、末尾は 08LE44149199。

- もう 1 回同じ設定で実行すると、「同名のファイルが既にある」として中止される。

## 5. ③ 20m メッシュを領域ポリゴンに合わせて作成

③は実機で未実行です。初回は「5.1 小さなデータで試す」から始めてください。

### 5.1 事前の準備

- 領域レイヤ（ポリゴン）：流域・森林計画区・県界・解析範囲など。このプラグインは領域を指定の系の座標へ変換します。領域全体が 1 つの系の有効範囲に収まっていること（収まらないとエラー）。

- 領域の名前が入っている属性（例：流域名）。レイヤ名に使います。同じ名前があっても \_2 を付けて区別します。

- マスクレイヤ（任意）：地域森林計画対象林など。空間索引を事前に作る必要はありません（プラグインがメモリ上で作ります）。

- 一部の領域だけを使う場合は、レイヤで地物を選択しておき、ダイアログで「選択地物のみ」にチェックを入れます。

### 5.2 小さなデータで試す（初回推奨）

1. 領域レイヤから流域 1〜2 件を選択する。

2. 「20m メッシュを領域ポリゴンに合わせて作成（領域ごとに別レイヤ）」を開く。

3. 系番号「系VIII」、測地系「JGD2011」を選ぶ。

4. 領域レイヤを選び、「選択地物のみ」にチェック。レイヤ名に使う属性を指定する。

5. マスクは指定しない。被覆率の最小値 0、細分数 5、「1 つの領域にだけ割り当てる」のままにする。

6. 出力先を「GeoPackage（推奨）」にし、「出力 GeoPackage」に新しいファイル名（例 test_ryuiki.gpkg）を指定する。既存ファイル名は使えません。

7. 「実行」を押し、ログ（「5.4 ログの読み方」）を確認する。

8. 「出力後にレイヤを読み込む」をオンにしておくと、完了後にレイヤが追加される。追加されないときは、ブラウザパネルから GeoPackage を開いて追加する。

### 5.3 本番（例：山梨県の流域×地域森林計画対象林）

1. 領域レイヤ：流域（全件）、レイヤ名用属性：流域名。

2. マスク：地域森林計画対象林。

3. 系VIII、JGD2011。

4. 被覆率の最小値：最初は 0。ログの被覆率分布を見て、シキイ値を決めて再実行する（既定値は根拠のない暫定値です）。

5. 細分数：5（標準）。精度が必要なときは 9 または 15（遅くなります）。

6. 領域をまたぐメッシュ：「1 つの領域にだけ割り当てる」（推奨）。一つのメッシュが複数のレイヤにあってよい場合だけ「重複して入れる」。

7. 出力先：GeoPackage。一時レイヤは小さな範囲の確認用だけに使う（上限 30 万件。超えると中止）。

### 5.4 ログの読み方

| ログの内容                                           | 意味                                                                                             | 見るところ                             |
|------------------------------------------------------|--------------------------------------------------------------------------------------------------|----------------------------------------|
| 領域: N 件 / 細分数 / しきい値 / マスクあり・なし    | 設定の確認                                                                                       | 意図どおりか                           |
| 採用 N メッシュ / 採用セル内の対象被覆面積 \[ha\]     | レイヤのメッシュ数と、採用セル内で対象にかかったサンプルの面積（近似）。セル全体の面積は N×0.04 ha | 領域面積と大きくずれていないか         |
| 被覆率の分布                                         | 境界セルの被覆率を 0〜10%、10〜25%、25〜50%、50〜75%、75〜90%、90〜100%未満、100% に区切った件数 | しきい値を決める材料                   |
| しきい値未満で採用しなかった面積                     | しきい値で落とした量                                                                             | 大きいときはしきい値を下げる           |
| 他の領域へ割り当てた面積                             | 領域の境界をまたいだメッシュの量                                                                 | 極端に大きいときは領域の重なりを確認   |
| 領域の面積とラスタ化した面積が 1% 以上ずれる（警告） | マスクなしのときだけ出る                                                                         | 細分数を上げる、またはジオメトリを確認 |
| 採用されたメッシュが 0 件（警告）                    | 空のレイヤが作られた                                                                             | 系・マスクとの重なり・しきい値を確認   |

### 5.5 結果の確認方法

1. 領域ごとのレイヤが GeoPackage にできている（ブラウザパネルで開いて確認）。

2. 領域の形に沿っている（領域レイヤを重ねて表示し、境界付近を拡大）。

3. 隣り合う領域のレイヤで、同じ JF20mID が重複していない（「1 つの領域にだけ割り当てる」の場合。しきい値を満たした候補の間での保証です）。

4. マスクを使ったとき、メッシュの中心付近がマスクの内側にある（採用されたセルは 20m の正方形のまま出力されるため、境界のセルはマスクの外へはみ出すことがあります。切り取りは行いません）。

5. 属性テーブルの cover_pct（被覆率）が境界で 100 未満、内部で 100 になっている。

6. 同じ設定で再実行すると、「同名のファイルが既にある」として中止される。

## 6. 注意事項

- ③の簡易手法は近似です。細分数 5 では被覆率の分解能が 4% です。厳密な面積が必要な場合は、細分数を上げるか、詳細手法（v0.5 予定）を待ってください。

- 大きな領域・細分数の大きい設定は時間とメモリを使います（未計測）。先に小さなデータで時間を見てください。

- 複数の系にまたがる地域（北海道、東京都、鹿児島県、沖縄県）は、系ごとに領域を分けて実行してください（自動切り分けは v0.5 予定）。系の境界付近では隣接する系のメッシュが重複します（仕様書が認める動作）。

- 属性名（JF20mID、file_zukaku、cover_pct）は暫定です。正式名が決まると変わる可能性があります。

- キャンセルしたときに残ったファイルは不完全です。削除してからやり直してください（上書きはしません）。

## 7. うまくいかないとき

| 症状（メッセージ）                                               | 原因の見立て                                                         | 対処                                                                                 |
|------------------------------------------------------------------|----------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| ツールボックスにグループが出ない                                 | プラグインが無効、または読込エラー                                   | 「プラグインの管理」で有効にする。QGIS を再起動。ログパネルの「Python エラー」を確認 |
| 「座標系 EPSG:xxxx を QGIS が認識できません」                    | 系VIII・JGD2011 以外の EPSG は未確認。PROJ データの問題              | 系VIII・JGD2011 で試す。ログの EPSG を Issue \#3 に報告。proj.db を手で差し替えない  |
| 「範囲が系の有効範囲（南北 ±300km、東西 ±160km）を超えています」 | 系番号の選択間違い、または範囲が大きすぎる                           | 系を見直す。ここは領域名がメッセージに出る（③）                                      |
| 「作成するメッシュが N 件で、上限 … を超えています」（①）        | 範囲が大きすぎる                                                     | 範囲を狭める、もしくは②を使う。ライン（格子線）なら広い範囲でも軽い                  |
| 「出力先に同名のファイルが既にある」（②③）                       | 上書きを拒否した                                                     | ファイル名を変える、または不要なファイルを手で削除してから再実行                     |
| 「整備年は西暦 4 桁の数字で」（②）                               | 年の入力誤り                                                         | 2026 のように 4 桁で入力                                                             |
| 「ファイル単位図郭名の形式が不正です」                           | 形式ミス                                                             | 08LE1 の形（系 2 桁＋英字 2 文字＋有1〜4）                                           |
| 「出力 GeoPackage を指定してください」（③）                      | 出力先が GeoPackage なのにファイル未指定                             | ファイル名を指定。一時レイヤにする場合は出力先を変える                               |
| 「一時レイヤのメッシュ数が上限を超えました」（③）                | 一時レイヤは上限つき                                                 | 出力先を GeoPackage にする                                                           |
| 「有効な領域がありません」（③）                                  | 領域レイヤが空、選択地物のみの選択漏れ、ジオメトリが空               | レイヤ・選択を確認                                                                   |
| エラーメッセージに osgeo や GDAL「Memory/MEM」が出る（③）        | ③のラスタ化が実機で動いていない（未検証箇所）                        | ログ全文を Issue \#6 に報告                                                          |
| GeoPackage にレイヤが 1 つしかない（③）                          | 複数レイヤ追加が実機で動いていない（未検証箇所）                     | ログ全文を Issue \#6 に報告                                                          |
| 「出力後にレイヤを読み込む」をオンにしたのにレイヤが追加されない | ②の読込オプションは未確認（Issue \#1）。レイヤ数が 10 を超えた可能性 | ブラウザパネルから GeoPackage を開いて追加。Issue \#1 に報告                         |

報告するときは、QGIS のバージョン、設定（スクリーンショット）、ログ全文を添えてください。パスや領域名に個人情報や非公開情報が含まれないか確認してから貼ってください。

## 8. 元に戻す方法

- 作成したファイル（GeoPackage）を手で削除する。プラグインは既存のデータを変更・削除しません。

- プラグインを元の版に戻すには、アンインストールして旧版の ZIP を再インストールする。
